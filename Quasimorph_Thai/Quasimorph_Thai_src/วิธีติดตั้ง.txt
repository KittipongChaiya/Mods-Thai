ม็อดภาษาไทย Quasimorph

รายละเอียด
เวอร์ชันม็อด: 1.3
ทดสอบกับเกมเวอร์ชัน: 1.0.3.578s.024ad60 (Unity 2022.3.62f2)

สิ่งที่เปลี่ยนไปจากเวอร์ชัน 1.2 (สำคัญ)
- ม็อดนี้ "ไม่แก้ไขไฟล์เกม" แม้แต่ไฟล์เดียวอีกต่อไป
  เวอร์ชัน 1.2 ใช้วิธีแก้ไฟล์ resources.assets โดยตรง ซึ่งผูกกับไฟล์เกมเวอร์ชันเดียว
  พอเกมอัปเดตเป็น 1.0.3 จึงติดตั้งไม่ได้
- เวอร์ชัน 1.3 ใช้ระบบม็อดของตัวเกมเอง (LocalUserPresets + CustomResources hook)
  จึงติดตั้งง่ายกว่า ถอนง่ายกว่า และมีโอกาสรอดเมื่อเกมอัปเดตในอนาคต
- ไม่ต้องใช้ BepInEx อีกต่อไป
- ไม่ต้องสำรองไฟล์เกม เพราะไม่มีไฟล์เกมถูกแก้

วิธีติดตั้ง
1. ปิดเกมก่อนติดตั้ง
2. แตกไฟล์ ZIP นี้ไว้ที่ไหนก็ได้ (ไม่ต้องแตกลงในโฟลเดอร์เกม)
3. ติดตั้ง Python 3.8 ขึ้นไปจาก https://www.python.org/downloads/
   (ตอนติดตั้งให้ติ๊ก `Add python.exe to PATH` และติ๊ก `py launcher`)
   ข้ามขั้นนี้ได้ถ้าเครื่องมี Python อยู่แล้ว
4. ดับเบิลคลิกไฟล์ `ติดตั้ง.py`
5. เปิดเกมตามปกติ
6. ไปที่ Options แล้วเลือกภาษา "ไทย" (จะอยู่ตรงตำแหน่งที่เคยเป็น English)

ตัวติดตั้งจะคัดลอกโฟลเดอร์ `mod` ไปไว้ที่
  %USERPROFILE%\AppData\LocalLow\Magnum Scriptum LTD\Quasimorph\LocalUserPresets\QuasimorphThai

วิธีถอนการติดตั้ง
- ลบโฟลเดอร์ QuasimorphThai ที่อยู่ในเส้นทางข้างบนทิ้ง เท่านั้น
- ไม่ต้อง Verify integrity ของ Steam และไม่ต้องลงเกมใหม่ เพราะไฟล์เกมไม่เคยถูกแก้

ถ้ามีปัญหา
- ดูไฟล์ log ที่ `QuasimorphThai.log` ในโฟลเดอร์ที่ติดตั้ง
  ไฟล์นี้จะบอกว่าโหลดตารางคำแปลได้กี่แถว และติดตั้งฟอนต์ไทยสำเร็จหรือไม่
- ถ้าตัวหนังสือขึ้นเป็นสี่เหลี่ยม แปลว่าฟอนต์ไม่ถูกติดตั้ง ให้ดูใน log ว่ามีบรรทัด
  "Installed Thai font into FontPreset" หรือไม่
- ถ้าเกมไม่เห็นม็อดเลย ให้ตรวจว่าโฟลเดอร์ปลายทางถูกต้อง และเกมเคยถูกเปิดอย่างน้อยหนึ่งครั้ง

ถ้าเกมอัปเดตเป็นเวอร์ชันใหม่
ม็อดนี้ออกแบบมาให้รอดจากการอัปเดตของเกม
- ม็อดไม่ได้แทนที่ตารางข้อความของเกม แต่จะอ่านตารางของเกมตอนเปิดเกม
  แล้ว "ทับ" คำแปลไทยลงไปโดยจับคู่ด้วยคีย์ของข้อความ
- ข้อความที่เกมเพิ่มเข้ามาใหม่จะแสดงเป็นภาษาอังกฤษตามปกติ ไม่ใช่ขึ้นเป็นชื่อคีย์ดิบๆ
- ภาษาอื่นอีกสิบภาษาจะมาจากไฟล์ของเกมเวอร์ชันที่ติดตั้งอยู่เสมอ
วิธีตรวจหลังเกมอัปเดต: เปิดเกมแล้วดูไฟล์ QuasimorphThai.log
ถ้าเห็นบรรทัด "Thai table ready: ... rows, ... translated" แสดงว่าใช้งานได้ปกติ
ไม่ต้องทำอะไรเพิ่ม

หมายเหตุเรื่องความครบถ้วนของคำแปล
ส่วนที่แปลแล้วครอบคลุมเมนู ปุ่ม HUD บันทึกการรบ หน้าตั้งค่า ระบบช่วยเหลือในเกม
ชื่อไอเทมและหมวดหมู่ไอเทมทั้งหมด สถานะ บาดแผล ความสามารถอาวุธ และคำสาปสนธิสัญญา
ข้อความส่วนที่ยังไม่ได้แปลจะแสดงเป็นภาษาอังกฤษตามเดิม ไม่ทำให้เกมพัง
