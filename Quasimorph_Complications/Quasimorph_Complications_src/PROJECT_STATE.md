## Decisions

- 2026-09-02 — **Drive complications ourselves rather than through the game's event
  system.** Every effect needed is already public: `SpawnSystem.SpawnFixedGroup`,
  `FireController.AddFire`, `ItemOnFloorSystem.SpawnItem`, `Data.Global`. Route A is
  elegant but gated behind whether `EventCollection` accepts new records — it declares
  only `TryGet`, unlike `ConfigRecordCollection<T>` which is what made Nemesis possible.
  The probe is shipped rather than discarded so the question gets answered.
- 2026-09-02 — **Zero Harmony patches**, and therefore no `PatchVerify`. Same position as
  Retinue, for the same reason: there is nothing to verify that `apicheck.py` has not
  already resolved at build time.
- 2026-09-02 — **One complication per raid.** Two at once is noise and makes it impossible
  to learn what any single one does.
- 2026-09-02 — **The trade is intrinsic, not fiscal.** Mission rewards are not touched at
  all. `ProcessMissionSuccessActions` is public but its structure is unverified, and a
  botched reward patch is a save-affecting bug. Each complication compensates in fiction
  instead — which is better design than a percentage anyway.
- 2026-09-02 — **Fire is capped three ways** — fixed seed count, minimum distance from the
  player, and a hard ceiling on lit cells. A fire that got away would make a floor
  unwinnable, which is a broken raid rather than a hard one.
- 2026-09-02 — **Reinforcements and rivals are modelled on creatures already on the
  floor.** No mob table of our own to be invalidated by a game update, and arrivals
  automatically inherit whatever Ruthless or Cap Enemy Spawn Tech did to the world.
- 2026-09-02 — **`LoudFloor` snapshots and restores the global radii**, and the scheduler
  restores again at floor start in case a floor ended without notice. Leaving the game
  permanently louder would be the worst bug this mod could have.
- 2026-09-02 — **No item id is hardcoded.** The cache pool is built by filtering
  `Data.Items` by item class, so it includes items other mods added. Ammo and medical
  only — a cache that can roll a better gun than you brought stops being compensation.
